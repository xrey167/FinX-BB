# RSI-001 — revision-sufficient persistent interfaces

Registered 2026-09-05 BEFORE numerical execution. Parent NIC001: aba7ffd6d91ddbd7db0359bea37cd4dd956a4d16. Status UNRUN. Architecture-contract test, not a major-invention claim.

## Question and interface

NIC001 leaves arbitrary joint nonlinear decoders open. Can any such decoder repair from a current compressed neural state, canonical source payload/version, and full identity/edge lineage if the original computation discarded distinctions needed by the rebuild?

Fix an immutable model and exogenous suffix. The tested repair interface contains ALL current arrays in the constructed memory, source old/new operation, and complete identity/edge/generation lineage; it EXCLUDES the numerical earlier context, historical activations, raw prefix, and data-dependent receipts not actually retained. The two histories may differ only in that discarded earlier context. This is an explicit interface test, NOT a claim that raw KV caches or systems retaining original source/context logs have the same limitation. Content-dependent hashes, pointers to available originals, receipts and checkpoints count as extra information if present.

A decoder exists precisely when the requested rebuilt target is constant on each fiber of its available interface. An explicit pair with identical interface bytes and different fresh targets rejects every decoder on that interface, not merely additive or low-rank ones. This is elementary function factorization/information theory, NOT a new theorem claim. Abstention/replay is allowed but does not constitute successful state-only repair.

## Fixed tests

1. Exact rational enumeration: 4 coordinates, alphabet {-3,-1,1,3}, all 256 earlier contexts. A rank-one delta overwrite erases that addressed row, with identical source metadata in every world. Compare all current interfaces and every write of a three-stage rational nonlinear counterfactual suffix. Count distinct omitted-source targets in the collapsed fiber. Include an exactly invertible beta=1/2 rational control and a retained-context positive control. Report the elementary auxiliary-information lower bound ceil(log2(distinct targets)); no novel lower-bound claim.
2. Stateful neural countermodel: five parameter seeds 0..4, three recurrent matrix-memory layers (4 keys x 8 values), four state-dependent nonlinear write steps. Two dyadic earlier contexts share the same background and differ only in the addressed row. A beta=1, unit-key, zero-value overwrite precedes all suffix writes. Verify identical complete current three-layer state AND identical old write trajectories; compare omission-to-NEVER fresh writes for both histories, including final arrays. Use independently implemented NumPy/PyTorch updates to check the operator, plus no-op/repeat controls. These are designed operator countermodels, not pretrained models, training seeds, or a second backbone.
3. Positive receipt: retain the discarded addressed row (8 float64 values), reconstruct the known source-boundary state, and use ordinary downstream replay. Compare every dependent write to full rebuild; do not infer no-replay novelty or full-system speed. The known-zero background is a declared simplifying condition. Show that restoring only the first layer and reusing stale upper states is not enough.
4. Finite arithmetic: enumerate 256 consecutive representable normal numbers beginning at 1 in bfloat16, float16, float32, float64. Apply the fixed scalar delta write h'=h+0.5*(1-h) with a strictly interior gate. Count collisions and verify exact rational arithmetic is injective on the same inputs. A bit collision disproves exact inversion in the evaluated arithmetic even where real-valued algebra is invertible. Treat ULP-scale residuals as exactness evidence, not language utility degradation. No underflow-only construction or saturated gate is required.
5. Source-blind audit control: identical present state yields identical deterministic present-state readout for both histories although deletion targets differ. This is an information-availability control, NOT a J-space/J-lens implementation or attack. Additional original-context interventions change the interface and may resolve the ambiguity.

## Fixed interpretation

All exact-equality claims use array shape/dtype/bytes within an execution or rational identities. Numerical effect sizes do not authorize approximate reuse. Preserve failed controls and implementation corrections. No exhaustive claim about all neural memory architectures or an exponential computation lower bound. A compact nonlinear decoder can succeed if its inputs retain a sufficient statistic for the declared revision family.

All application gates remain NOT EVALUATED: >=10x total mutation-to-ready, <=5% throughput loss, matched total memory, >=95% reading/paraphrase/lifecycle, >=90% scoped UNKNOWN, generic divergence/exact bypass, independent J-space, generation/publication safety, trained seeds and second-backbone qualification.
