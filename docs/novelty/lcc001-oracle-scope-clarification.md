# LCC-001 — exact observer scope after source review

Date: 2026-09-05. This clarification changes no code, thresholds or measurements. It prevents an overbroad interpretation of the phrase "local derivatives" in the registration/result.

## Arm B's measured derivatives

The 15,120 derivative-vector comparisons are derivatives of the chosen state H with respect to **the context x and source-presence variable m**, through total order four. The arbitrary-finite-order neighbourhood argument refers to these same input variables.

The equal forward traces include shared gate preactivations/activations and H. They do **not** include every derivative with respect to every internal node or network parameter. In particular, the derivative of H with respect to the internal gate-product variable can reveal the different final connection (zero versus v). A richer white-box or internal-edge-derivative oracle can therefore distinguish this particular constructed pair.

Consequently Arm B does NOT prove that arbitrary J-lens implementations, every internal causal intervention, or all white-box neural support-discovery methods are unable to certify a domain. It proves the stated limitation of finite source/context-response observations without extra structural information or complete identification assumptions. A lens computed solely from H using the same downstream continuation is included in that restricted observer; a method inspecting the differing upstream connection is not.

## Arm A is a different and stronger information-loss statement

The provenance collision uses **the same model and same authority registry**, not two different sets of model weights. The only missing information is which equal-valued source generation produced the particular unlabelled state. Identical post-merge numerical states cannot reconstruct that missing historical origin. A retained routing trace, source identity encoded in the state, or other origin information escapes the restriction.

## Programme interpretation

Retire state-only historical origin recovery when origin was not preserved, and finite source/context-probe-only universal support certification. Do not retire J-space as independent empirical audit, all causal discovery, or white-box completeness proofs. No real J-lens was executed and no trained-reader attack result follows.
