# E-000093 prior-art screen — mutation-local neural support

Date: 2026-09-05. This is a technical screen, not legal advice and not a patentability opinion.

## Strongest collision found: PlaceMem (2026)

**PlaceMem: Toward a Compute-Aware Memory Plane for Lifelong Agents** (Ganguly, arXiv:2607.04089, July 2026) is a strong collision with any broad claim that one versioned memory identity should bind semantic meaning, validity, dependencies and reusable runtime state.

PlaceMem explicitly proposes versioned capsules that unify semantic content and reusable compute artifacts under one correction-aware identity; it performs correction-driven cascading invalidation and KV-aware routing. Its paper also names optional layer-frontier checkpoints, but states that layer-frontier replay/deeper engine integration is future work rather than a claimed implemented engine feature.

**Consequence:** we must not claim novelty for:

- versioned semantic memory + runtime artifact identity;
- dependency-graph invalidation of KV/runtime artifacts;
- correction-aware cache reuse as a control-plane abstraction;
- semantic freshness gates around KV reuse.

Those ideas are materially occupied by PlaceMem and neighboring systems.

## Selective recomputation collision

**ProphetKV** (Wang et al., arXiv:2602.02579) selectively recomputes query-relevant KV tokens and reports high retained accuracy at a limited recomputation budget.

**InfoFlow KV** (Teng et al., arXiv:2603.05353) explicitly casts selective KV recomputation as an information-flow problem and chooses tokens likely to propagate useful information.

Other cache-fusion systems similarly select partial token/chunk state for recomputation after assembling reused KV state.

**Consequence:** we must not claim novelty for generic selective recomputation, information-flow-aware cache repair, query-conditioned recomputation, or partial KV refresh.

## Invalidation-contract collision

**Invalidation Contracts for Cross-Episode Agent Memory** (Wu & Canedo, arXiv:2609.00243) attaches version stamps/cacheability hints to reusable agent-memory artifacts and demonstrates row-granularity stale-entry invalidation.

**Consequence:** version stamps plus row-level invalidation are not a sufficient novelty center.

## Knowledge-editing collision

Knowledge editing benchmarks and methods already test counterfactual fact changes, paraphrase generalization, locality/non-interference, and propagation through multi-hop reasoning. Therefore `edit fact A while preserving unrelated fact B` is not new by itself.

## Surviving technical gap to test

The remaining candidate is substantially narrower:

> A neural knowledge reader is *trained under counterfactual canonical-memory mutations* so that the model's own materialized causal workspace has a small mutation-local dependency support; runtime validity/reuse of hidden/KV/layer state is then derived from that neural support and the canonical Pod generation, rather than attached only by an external cache-control plane.

Key distinctions from the strongest neighboring work:

1. **Training target, not only serving policy.** PlaceMem and selective-recomputation systems reason about already-produced artifacts. E93 asks whether the reader can be trained so irrelevant canonical mutations cease to perturb its neural state in the first place.
2. **Knowledge-identity intervention.** The counterfactual variable is a canonical Pod payload/lifecycle generation, not a query token chosen after cache assembly.
3. **Neural-state invariance is measured directly.** Hidden state, routing, full logits, KV and stale-vs-fresh continuation are compared under a reference-irrelevant canonical mutation.
4. **Future exact-support target.** The intended end state is not merely low numerical sensitivity but a finite verified support such that unchanged support implies exact reusable neural state.
5. **Symlink fanout semantics.** Multiple linguistic/symbolic access paths resolve to one canonical Pod lifecycle rather than maintaining independent edited copies.

## What E-000093 can establish

A positive E93 can establish only the empirical premise that counterfactual mutation-locality is trainable without destroying reader capability. It cannot establish novelty because continuous invariance objectives, counterfactual training, sparse attention and consistency regularization all have prior art separately.

## What would be materially stronger

The next promotion should require all of:

- strict held-out symlink reader capability;
- canonical Pod edit/revoke semantics;
- learned mutation-local neural support;
- an exact or certifiably bounded dependency representation generated by the reader;
- selective reuse/invalidation of actual materialized hidden/KV/layer state based on that support;
- a demonstrated asymptotic or measured mutation-to-ready advantage over global invalidation/recompute;
- no stale-generation resurrection under concurrency/race tests.

Only that integrated mechanism is currently worth screening as a possible technical novelty center.

## Current disposition

**Broad CAVI/PlaceMem-like control-plane claim: COLLIDED.**

**Generic sparse/selective KV recomputation claim: COLLIDED.**

**Counterfactual mutation-local neural support trained inside a canonical Symlink–J-space–Pod reader and used to certify selective derived-state validity: OPEN RESEARCH GAP, not yet a novelty claim.**
