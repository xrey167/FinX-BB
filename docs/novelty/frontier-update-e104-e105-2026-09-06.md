# Frontier update after E-000104 / E-000105

Date: 2026-09-06
Status: **research-boundary update; no invention promoted**

## New closed structural families

Two additional exact fleet-update constructions work technically but collapse to strong generic baselines:

1. **E-000104 tensor-train/MPS local-core lifecycle updates** — exact compact high-order interaction and 3.0x–9.8x arithmetic reduction versus full contraction in the registered toy domain, but an independent generic tensor-network updater using the identical cores/environments obtains exactly the same states and exactly the same mutation work.
2. **E-000105 stable-gate piecewise-affine cohort transport** — exact one-correction-per-cohort fleet updates with 89.78x–541.33x descriptive arithmetic reduction versus independent replay in the registered structural domain, but ordinary fixed-region specialization / forward-mode sensitivity obtains exactly the same states and mutation work.

Neither is a major invention seam. Their benefits belong to standard factorization / exact regional algebra once the same representation is exposed to the baseline.

## Strong external boundary: addressable influence vs entangled replay

Ramesh, **Subtract or Replay? Exact Deletion from Language-Model Memory** (arXiv:2607.27539, 2026) is especially important to the programme boundary. It explicitly separates:

- addressable memory, where algebraic decrement/refit can reach a declared deletion reference; and
- recurrent/entangled memory, where later transitions and writes become record-dependent and exact restoration requires checkpoint rewind/replay under the evaluated interface.

The paper reports a native Kimi Delta Attention record contribution varying by 12–49% with suffix and identifies changed later transition/write terms as the reason a fixed boundary receipt does not reproduce native omission. In its deterministic replay arm, the surviving suffix is replayed to match record-omitted logits and audited recurrent state exactly. Source: https://arxiv.org/abs/2607.27539

Its companion **Forgetful Attention: A Trainable Support-Vector Memory with Certified Selection and Exact Unlearning** (arXiv:2607.12204) further crowds architecture-by-design exact deletion for addressable memories. Source: https://arxiv.org/abs/2607.12204

This is not treated as a proof of impossibility for FinX-BB, but it independently reinforces the same boundary reached by E-000095/096/101: once a mutable record changes subsequent nonlinear writes/transitions, a fixed cross-context receipt is not enough; exact replay remains the strong reference unless the architecture exposes a stronger exact sufficient state.

## Piecewise-affine prior-art boundary

Current exact piecewise-affine work also makes E-000105's baseline unavoidable:

- **AffineLens** (arXiv:2605.06218, 2026) explicitly exploits exact affine restriction under fixed activation patterns and enumerates continuous piecewise-affine regions.
- **Mechanistic Interpretability of ReLU Neural Networks Through Piecewise-Affine Mapping** (Machine Learning, 2026, DOI 10.1007/s10994-025-06957-0) analyzes ReLU models via piecewise-affine maps.
- **YANNs** (arXiv:2505.07054, 2025) gives exact efficient representations of piecewise-affine functions.

Therefore an exact Jacobian library indexed by stable gates, region IDs, or activation signatures receives no standalone novelty credit.

## Surviving technical seams

### A. Exact transport across Pod-induced nonlinear region transitions

E-000105 only covers a fixed activation signature. A successor may still be technically interesting if a Pod revision changes gates/regions yet an exact compact transition witness updates already-materialized state materially faster than:

- generic exact branch/region evaluation given identical state;
- last-read-site patch + minimal suffix recomputation;
- exact residual/KV reconstruction;
- checkpoint rewind/replay where subsequent writes are edit-dependent.

A finite region label or precomputed transition table by itself is not sufficient; a generic exact evaluator must receive the identical representation as baseline.

### B. Neural causal-lineage discovery/certification

Transport has become heavily constrained, so the parallel remaining programme seam is **discovered neural causal lineage** rather than supplied dependency metadata. Current 2026 work is active but largely observational/attribution-oriented:

- Xiao et al., `arXiv:2608.30198`, traces error propagation through memory-update vs question-feedback pathways using interventions.
- Yan et al., `arXiv:2606.03085` / ACL 2026, performs multi-component causal tracing over attention/MLP subsets.
- Mechanistic Data Attribution (`arXiv:2601.21996`) traces interpretable units to influential training samples with influence functions.

A FinX-BB lineage mechanism would need to **certify the exact source set needed for a lifecycle repair/revocation operation**, not merely rank influence or explain a behavior, and must outperform ordinary explicit provenance/dependency tracking on a guarantee-matched task.

## Current major-break status

**No major invention is promoted.** The increasingly consistent boundary is:

- addressable/factorized state can be updated exactly, but generic algebra usually inherits the same advantage;
- entangled nonlinear state changes later computation, and exact restoration tends to require replay unless a new exact sufficient representation exists.

The next invention candidate must break that dichotomy rather than rename one side of it.
